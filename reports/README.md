# Smart Healthcare Management & Analytics Platform

## Project Overview

The Smart Healthcare Management & Analytics Platform is a portfolio-based full-stack healthcare application developed to demonstrate software engineering, backend development, frontend development, database design, SQL analytics, and business intelligence skills using realistic hospital sample data.

This project focuses on hospital operations such as patient registration, doctor management, appointments, billing, laboratory services, pharmacy, inventory, staff management, and executive analytics dashboards.
